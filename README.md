# myqdui

*"My Quick & Dirty UI!"*

A strongly opinionated React and TypeScript component library. Built as a personal project to demonstrate design-engineering work to prospective employers — and built properly, so it's genuinely usable in any modern React or Next.js app.

**Pre-1.0 — in active development.** Anything may change: components may be renamed, reworked, or removed until 1.0.

Free to use under the MIT licence. Originated as a personal project and may or may not be actively maintained.
